
The goal of this project is to develop Windows software that uses computer vision and artificial intelligence to analyze real-time soccer broadcasts. The system should automate the identification of crucial moments in game plays, such as goals or potential offsides, for quick analysis.

Essential Features:

1. Continuous Broadcast Monitoring: The software should monitor the soccer broadcast in real time, preferably keeping the last 15-20 seconds in RAM for fast processing.
2. Shortcut Activation: By pressing a keyboard shortcut (e.g., F8), the system should automatically identify the relevant moment for offside or goal analysis.
3. Precise Frame Identification: The software should be able to identify the exact frame of contact with the ball (pass, shot, cross) that initiated the relevant play. This includes complex scenarios, such as goals after rebounds (where the frame of the initial shot is necessary) or deep crosses.
4. Immediate Display: After activation, a window should display the best candidate frame in approximately 1-3 seconds (maximum 5 seconds).
5. Frame Navigation: The user should be able to advance or rewind one frame at a time (up/down arrows).
6. Candidate Selection: If the AI identifies the wrong action, the user should be able to switch between other candidate frames suggested by the artificial intelligence (up/down arrows).

Response speed is an absolute priority to ensure the tool's usefulness in a live game analysis context. The ideal developer will have experience with computer vision, AI, and Windows desktop application development, and will be available for audio/video communication for detailed demonstrations and discussions about game situations.
